# webcpp 0.1.0

webcpp 0.1.0 is out.

## New libraries

- **config**: webcpp's configuration, which every library includes first: the target, exceptions and the version, from R.
- **document**: a header-only JSON document for C++20 that behaves as JavaScript does, exact in decimal, in one relocatable binary image, with a JavaScript module, from R.
- **idna**: a header-only library of internationalized domain names for C++20: Punycode, UTS 46 and IDNA2008 validity over Unicode 17.0.0 tables, from R.
- **lexical**: header-only validators of JSON Schema's string formats for C++20, allocating nothing, each also a Boost.URL grammar rule, from R.
- **pratt**: a header-only Pratt-parsing engine for C++20, with a decimal calculator built on it, from R.
- **trystero**: a port of Trystero 0.26.0, serverless WebRTC rooms wire-compatible with the original, for C++20, from R.
- **wasi**: a header-only HTTP handler for C++20 programs built as WebAssembly components, covering WASI 0.2 and WASI 0.3, from R.
- **xactor**: a header-only, deterministic actor system for C++20, from R.
- **xstate**: a header-only port of XState's state machines and actors for C++20, from R.

## Highlights

- **New libraries**: Nine C++20 libraries provide JSON, domain names, parsers, WebRTC rooms, WASI handlers and actor systems.
- **Security & reliability**: Trystero rooms share authenticated app connections while separate passwords remain isolated in distinct apps.
- **Developer experience**: Reproducible source packages include documentation, licenses and pinned source dependencies.

## Tools and build

- Fixed source distributions rejecting pinned site and third-party dependencies.
- Changed release checks to accept the tested compiler subset.
- Added agent skills with validated metadata for common contributor workflows.

## Trystero migration

Construct `webcpp::trystero::app` and call `app::join` instead of constructing a standalone
room with `room_config`. Put the immutable password in `app_config::password`; all rooms of
that app share it. Different passwords require separate apps and distinct peer IDs. The
Trystero JS 0.26.0 wire is unchanged. A remote JS page mixing room passwords retains the
upstream one-way-handshake limitation.

## Verification

This release is prepared without CI at the owner's request. Local checks cover the collection's
ordinary tests and examples on Apple Clang 21 (macOS 27), Emscripten 6.0.11 and GCC 15.2. On
GCC, Trystero's core is tested; its native backend uses dependencies built with libc++ and is
validated with Clang. Trystero also passes ASan/UBSan, its protocol oracle, 27 native and 24
browser interoperability scenarios against JS 0.26.0. Strict documentation and release-tool
checks pass. Windows, Linux container and WASI runtime lanes were not rerun for this release.

The archive includes the complete built HTML documentation. The hosted site is updated by CI,
so this publication does not redeploy it.
