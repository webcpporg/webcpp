# Wasmtime 50.0.1 project-wide upgrade

The owner requested Wasmtime 50 across the project and every library during the
initial Beast implementation. The latest official patch is 50.0.1, released on
2026-10-29. This upgrade continues the active implementation and CI corrections;
it does not authorize a new remote CI run or change the user's Homebrew installation.

## Scope and decisions

- Pin 50.0.1 in the shared installer for Linux/macOS, x64/ARM64, using each official
  release asset's SHA-256. Download and verify all four archives.
- Use the same runtime for WASIp2, WASIp3 single and WASIp3 cooperative variants.
  Keep the P3 capability-aware launcher and the SDK's cooperative EH restriction.
- Update current build instructions, tool diagnostics, lane names, test expectations
  and library runtime contracts. Preserve dated measurements and generated report
  samples as history; do not relabel old measurements as new results.
- Install into the isolated checkout's ignored `.local/wasmtime-50/` and select it
  explicitly through PATH and WASMTIME for every verification command.


The installer and actions suite log is `/tmp/webcpp-wasmtime50-actions-test.log`.
The shared runtime's previous pin was 47.0.3; prior cooperative tests used 49.0.3.
These remain historical evidence, not the selected toolchain after this upgrade.

## Regressions found by the wider matrix

- Lexical's allocation control was optimized away in Release. The same component
  failed under 47.0.3 and 50.0.1. Test-scoped `-fno-builtin` preserves its exact
  counting assertion; `allocation_release` now exercises this in default Debug
  requests too. Twenty fresh native/P2/P3/Emscripten executions passed.
- Config's quick-start example correctly printed `exceptions off`, but compared it
  with an `on` transcript. Complementary example targets now share the original
  implementation and select the recorded output for each exception mode. Ten fresh
  native/P2/P3/Emscripten executions passed, with no forced exception mode.
- The whole-tree lint passed 897 compilation commands over 406 translation units.
  The later Lexical flags and Config wrapper passed focused lint with refreshed B2
  commands. Independent review accepted these changes and the runtime upgrade.
- Four general P3 instructions still bypassed the network-capable launcher. The
  same Beast socket program failed with plain Wasmtime and passed with the shared
  launcher; the general README, agent guide and coding guide now use it.
